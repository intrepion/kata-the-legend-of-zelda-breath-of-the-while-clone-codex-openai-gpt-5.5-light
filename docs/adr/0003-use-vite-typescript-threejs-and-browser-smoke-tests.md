# Use Vite, TypeScript, Three.js, and Browser Smoke Tests

We will use Vite, TypeScript, Three.js, and Playwright-style browser smoke coverage for the initial implementation. A dependency-free static app would be simpler to ship, but a third-person 3D adventure needs maintainable scene, camera, input, and verification structure; completion requires browser evidence for movement, traversal, tower reveal, shrine completion, a nonblank 3D scene, and a clean console.
