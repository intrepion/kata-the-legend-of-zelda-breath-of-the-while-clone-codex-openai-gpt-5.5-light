# Bound the First Slice to Traversal, Physics, and Lightweight Combat

The first slice will constrain stamina to climbing, gliding, and sprinting; award the glider from the tower; use one physics shrine; and include an optional enemy camp with lightweight weapon pickups. Cooking, swimming, full gear durability, mandatory combat progression, and broad weather systems are deferred so the first playable run can prove the open-air adventure loop without diluting traversal and shrine quality.
