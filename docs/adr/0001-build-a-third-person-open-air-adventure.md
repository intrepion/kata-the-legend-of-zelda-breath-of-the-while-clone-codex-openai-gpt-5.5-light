# Build a Third-Person Open-Air Adventure

We will build an original third-person open-air adventure rather than a top-down, 2.5D, dashboard, or purely themed Zelda-like game. The defining acceptance criteria are a full-screen 3D wilderness, player-following camera, readable distant landmarks, and traversal-led exploration, because the requested reference is defined by perspective, scale, and movement freedom more than by names or iconography.
